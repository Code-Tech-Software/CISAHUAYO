    Configuración nueva. El sistema no tenía umbrales para estas alertas ni una calificación aprobatoria configurada. Los valores iniciales son una propuesta para empezar, no reglas institucionales: revísalos con la dirección de cada nivel.

    Valores propuestos: {{ propuestos.faltas_acumuladas }} faltas sin justificar en el periodo; {{ propuestos.faltas_consecutivas }} faltas seguidas; inasistencia mayor que {{ propuestos.inasistencia_maxima }} % con al menos {{ propuestos.dias_minimos }} días con registro; calificación aprobatoria {{ propuestos.calificacion_aprobatoria }} (la que el portal ya marca como reprobatoria); {{ propuestos.materias_reprobadas }} materia reprobada; promedio menor que {{ propuestos.promedio_minimo }}; descenso de {{ propuestos.descenso_minimo }} punto entre dos periodos; prioridad alta con {{ propuestos.reprobadas_prioridad_alta }} materias reprobadas.

    Las alertas son preventivas: no generan sanciones ni cambian calificaciones, y se recalculan con los registros de cada momento.
